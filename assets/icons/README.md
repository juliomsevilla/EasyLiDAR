# Iconos de EasyLiDAR

SVG propios, dibujados desde cero (no derivan de arcskin, QGIS ni Esri).

Para añadir uno: guarda `nombre.svg` aquí y úsalo como `"@nombre"` en `ribbon::big_button`,
`small_button`, `icon_button` o `draw_icon`. No hay que registrarlo en el código.

## Estilo
- `viewBox="0 0 24 24"`, trazo `1.5` (`2` para flechas y acentos), `round` en extremos y uniones.
- Planos, sin degradados ni sombras.
- Neutros con `currentColor` (toma el color del tema claro/oscuro).
- Acentos fijos: azul `#007ac2` (borde `#09496f`), relleno claro `#d6e8f5`, verde `#3a9e3a`
  (borde `#256b25`), naranja `#e8912d`, rojo `#d64545`, amarillo `#f2c94c` (borde `#a8841c`).
- Insignias de acción (añadir, quitar) en un círculo de 5 px en la esquina inferior derecha.
